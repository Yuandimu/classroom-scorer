==================================================
  课堂实录评分工具 - 使用说明
==================================================

【一、首次安装（只需一次）】

1. 双击运行「安装并启动.bat」
   - 会自动检查 Python、安装依赖、检查 ffmpeg
   - 如提示需要安装 ffmpeg，按提示操作即可（约 1 分钟）

2. 安装完成后浏览器会自动打开评分页面
   - 地址：http://localhost:8501
   - 如果浏览器没自动打开，手动访问上面的地址

【二、日常使用】

每次使用只需：
  双击「安装并启动.bat」→ 浏览器打开 → 开始评分

【三、评分配置】

页面左侧是配置面板，请按以下步骤设置：

1. 选择接口（推荐二选一）：
   ┌─────────────────────────────────────┐
   │ 方式A：Ollama 本地模式（免费）      │
   │   - 选择「Ollama（本地，免费）」  │
   │   - 需先安装 Ollama + 下载模型    │
   │   - 详见下方「Ollama 本地模式」   │
   ├─────────────────────────────────────┤
   │ 方式B：在线 API（推荐）           │
   │   - 选择「DeepSeek（推荐）」      │
   │   - 填入 API Key（去官网注册获取）│
   │   - 或选择「智谱 GLM（免费）」    │
   └─────────────────────────────────────┘

2. 选择 Whisper 模型（语音转文字精度）
   - tiny：最快，精度一般（推荐先试）
   - base：推荐，速度精度平衡
   - small：更准但慢 2 倍

3. 上传视频（最多 10 个，每个 ≤1GB）
   - 支持 MP4/AVI/MOV 等格式
   - 或勾选「使用文字模式」直接粘贴课堂文字记录

4. 点击「开始批量评分」
   - 首次运行会下载 Whisper 模型（走国内镜像，约 1-3 分钟）
   - 之后复用缓存，秒开

【四、Ollama 本地模式安装（可选）】

如果想完全本地运行、不用 API Key：

1. 前往 https://ollama.com 下载安装 Ollama
2. 打开命令行，运行：ollama pull qwen2.5:7b
3. 回到工具，选择「Ollama（本地，免费）」，无需填 API Key

【五、常见问题】

Q：提示「未检测到 Python」
A：前往 https://www.python.org/downloads/ 下载安装，安装时勾选
   「Add Python to PATH」

Q：ffmpeg 安装失败
A：手动下载 https://www.gyan.dev/ffmpeg/builds/，解压后将 bin 目录
   加入系统 PATH，或联系 IT 协助

Q：评分很慢
A：Whisper 转录耗时与视频长度成正比，10 分钟视频约 3-8 分钟
   可先用「文字模式」粘贴已有文字记录，跳过转录步骤

Q：Windows 防火墙弹窗
A：点击「允许访问」，这是 Streamlit 本地服务的正常提示
